My Books

Works fully offline. Your place in each book and your notes are saved automatically.

⚠ This window can't save anything: your page and notes will be lost when you close it.
Open the file C:\SelfWork\Books\Reader\Book Reader.html by double-clicking it in File Explorer (it opens in Chrome).

Tip: add each book once. It is copied into this device, so after that it opens without the original file and without internet. Each device keeps its own books, page and notes. Use “Back up all notes” to keep a copy of your notes.
