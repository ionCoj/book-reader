# Book Reader

An offline PDF reader that runs in the browser and can be installed on iPhone/iPad ("Add to Home Screen").

- Remembers the page you stopped on, per book
- Table of contents, page jump, zoom, night mode, swipe to turn pages
- Notes per page, with quoting of selected text, search and export
- Works with no internet after the first visit (service worker); books and notes stay on the device (IndexedDB)

Built with plain HTML/JS and [PDF.js](https://mozilla.github.io/pdf.js/) 3.11. No books are included: add your own PDFs in the app.
